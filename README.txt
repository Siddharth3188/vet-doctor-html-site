VETERINARY CLINIC DEMO - customise per client
1. Edit the CONFIG block at the top of script.js (names, phone, WhatsApp, address, hours, Google Maps URL).
2. Replace images in /images (currently placeholder illustrations, NOT photographs):
   vet-hero (vet + dog, face visible), vet-profile (approved portrait), dog-consultation, cat-care, happy-dog, clinic-interior.
   Keep names, or update the src in index.html (e.g. .webp/.jpg).
3. Text marked [ ] in index.html (diagnostics, animals treated) must be confirmed with the vet.
4. Remove service cards the clinic does not offer (e.g. data-optional="grooming").
